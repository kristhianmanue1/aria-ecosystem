# ARIA — ecosistema de proyectos independientes

ARIA reúne proyectos autónomos que exploran capacidades para sistemas agénticos de inteligencia artificial: fuentes, memoria, ejecución, metodología y evaluación. Su vinculación futura debe responder a necesidades comprobadas y contratos explícitos, no a la obligación de compartir un repositorio o almacenamiento.

Este repositorio es el **punto de entrada documental público del ecosistema**. Conserva orientación, decisiones transversales expresamente adoptadas y propuestas de trabajo. No contiene los repositorios de los componentes ni demuestra que exista una plataforma integrada operativa.

## Cómo se relaciona con los proyectos

Cada proyecto conserva su repositorio, propietarios contractuales, historial, versiones y decisiones. Una referencia desde ARIA no implica dependencia de ejecución, aprobación técnica ni transferencia de autoridad.

**Pinax** conserva la función de catálogo y compilador del mapa a partir de declaraciones de cada proyecto: valida su forma, no su veracidad. ARIA no crea aquí un segundo catálogo canónico ni copia el schema o validador de Pinax. La inclusión e identidad de componentes siguen bajo decisión del Mediador.

**Kratos** conserva el papel previsto de orquestador final. Este repositorio no le atribuye estándar ni auditoría. Una responsabilidad arquitectónica declarada no acredita su implementación.

Las referencias públicas a repositorios y las fotografías de capacidades se incorporarán cuando se hayan comprobado sus destinos, visibilidad, fuentes y fecha. Esta primera entrega no publica el inventario privado de trabajo ni una matriz de madurez no verificada.

## Lo que este repositorio no es

- Un monorepo, una distribución o un conjunto de submódulos de los proyectos.
- Un runtime, un almacén de memoria o un sustituto de Ágora, AN-KLA o Pinax.
- Un estándar universal, un auditor independiente o una fuente automática de permisos.
- Un respaldo de corpus, conversaciones, credenciales o expedientes internos.

## Estado

Base documental pública inicial, fechada el **2026-10-02**. La decisión adoptada en esta entrega es la organización de este repositorio; las prioridades del roadmap siguen siendo propuestas. No se anuncian nuevas integraciones, releases de componentes ni garantías de funcionamiento conjunto.
